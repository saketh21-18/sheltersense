# ShelterSense AI — GitHub Pages build

This package is prepared for a GitHub Pages project site.

Important:
- `index.html` is at the repository root.
- CSS and app JS are under `static/`.
- The Python file is included for reference; GitHub Pages does not run Python.
- The original project references additional JS files (`shelter3d.js`, `map.js`, `charts.js`, `report.js`) that were not among the uploaded files, so those features may be limited until those files are added.
